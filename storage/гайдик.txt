В поле Search введи manager_id.

В поле Replace введи editor_id.

Под полями есть Files to include – оставь пустым или укажи src/ для ограничения.

Нажми кнопку Replace All (справа от поля Replace, иконка "Заменить всё").

VS Code заменит все вхождения во всех файлах проекта. Подтверди действие.

Важно:

Если замена нужна только в определённых файлах, перед Replace All можно просмотреть список найденных мест.

Если в базе данных есть поле manager_id, его также нужно переименовать через SQL:
